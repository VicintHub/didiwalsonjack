# didiwalsonjack
Personal brand website for Mrs. Didi Walson-Jack, OON, mni — former Head of the Civil Service of the Federation.

## Contents
The HTML embedded on the live site (didiwalsonjack.com), rebranded and corrected against the CV, Profile, Legacy Report and Scorecard. See `docs/content-audit.md` for every change and `docs/BRAND.md` for the brand rules.

| File | Page |
|---|---|
| `index.html` | Home |
| `about.html` | About |
| `career.html` | Career & Achievements |
| `books.html` | Books |
| `contact.html` | Contact |
| `partials/header.html`, `partials/footer.html` | Shared header/footer widgets used by the Speeches, Photo and Video pages |

Each page is a self-contained document (inline CSS and JavaScript). Logos and favicons are in `assets/Logos`.

Speeches, Photo and Video are generated by the site's Chronicle plugin (6 speeches, 6 videos, 8 photo events), so they have no standalone embed; only their header/footer are saved here.
